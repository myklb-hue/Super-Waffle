Switching
the toggle in a block's header, shown while hovered or selected; two positions when there is no third view
dbl-clickon the header cycles the views
⌘Eopens the third view of the selected block
The third view is Code for a custom block and Stage for a block with a live picture: Avatar, Webcam, Display, Terminal, Object detection. The view is remembered per block, per graph.
Resizing
Drag the corner. In Summary it sets width and the body reflows. In Stage or Code it sets width and height; the picture scales, the code scrolls.
Snaps to the 22 px grid. Minimum is the compact size. Remembered per block, per graph. An Avatar keeps its aspect unless you unlock it in the inspector.
Big programs
Code drawer — full width under the canvas, beside Console and Trace; the block stays compact above it.
File mode — point the block at a file and edit in your own editor; the block reloads on save.
Split into blocks — a file with several @block functions makes several blocks, one per function.
